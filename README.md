# TurnablePage Minimal Reproducible Example

A minimal Flutter app demonstrating the `turnable_page` library.

## Features

- 5 colored pages
- Swipe to flip pages
- Navigation buttons (previous/next)

## Running

```bash
flutter pub get
flutter run
```

## Key Components

- **TurnablePage**: Main widget for page flipping
- **PageFlipController**: Controls page navigation programmatically
- **builder**: Creates each page with index and constraints
